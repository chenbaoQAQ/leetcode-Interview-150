L005. 多数元素 🗳️

    给定一个大小为 n 的数组 nums ，返回其中的多数元素（出现次数大于 ⌊ n/2 ⌋ 的元素）。
核心思路

    摩尔投票算法 (Boyer-Moore)：

        抵消逻辑：将数组看作不同势力的对拼，多数派人数超过一半，一换一也能活到最后。

        流程：选定候选人，遇到同类票数 +1，遇到异类票数 -1。票数归零则换人。

    排序中点法：排序后，n/2 位置对应的数一定是多数元素。

复杂度分析

    时间复杂度: O(n) — 摩尔投票法效率极高。

    空间复杂度: O(1) — 仅需候选人和计数器。

关键点总结

    前提条件：该算法生效的前提是数组中一定存在多数元素。
