L019. 最后一个单词的长度 📏

        给你一个字符串 s，由若干单词组成，单词前后用一些空格字符隔开。返回字符串中 最后一个 单词的长度。
核心思路

    反向扫描 (Backward Scan)：

        题目要求的是“最后一个”单词，因此从后往前遍历是最直观且高效的。

    两个阶段：

        处理后缀空格：末尾的空格不属于任何单词，必须先将其排除。

        确定单词边界：从第一个非空格字符开始计数，直到遇到下一个空格。

    边界处理：

        整个字符串可能只包含一个单词。

        字符串可能以多个空格结尾。

复杂度分析

    时间复杂度: O(n) — 最坏情况下（如没有空格）需要遍历整个字符串。

    空间复杂度: O(1) — 仅使用了常数级的辅助变量。

关键点总结

    避免使用 split()：虽然 s.trim().split(" ") 也能解决，但会产生额外的 O(n) 空间开销（创建字符串数组），在面试中手动反向遍历更受青睐。

    指针安全性：在 while 循环中始终检查 i >= 0 以防索引越界。
