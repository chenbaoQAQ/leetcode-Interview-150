L013. 除自身以外数组的乘积 ✖️

        给你一个整数数组 nums，返回数组 answer ，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。题目数据保证结果在 32 位整数范围内。请 不要使用除法，且在 O(n) 时间复杂度内完成。
核心思路

    左右乘积分解：由于不能用除法，我们可以将每个位置的结果看作：(它左边所有数的乘积) * (它右边所有数的乘积)。

    两次遍历：

        第一遍（从左往右）：计算每个元素左侧的乘积并存入结果数组。

        第二遍（从右往左）：用一个变量记录右侧累计乘积，并实时乘以结果数组中已有的左侧积。

    空间优化：除了返回的数组外，只使用常数空间来完成计算。

复杂度分析

    时间复杂度: O(n) — 数组遍历两次（或三遍，取决于实现）。

    空间复杂度: O(1) — 注意：输出数组不计入额外空间。

关键点总结

    避开除法：除法在遇到 0 时会失效，而乘积分解法则非常稳健。

    初始化：左侧积的第一个元素和右侧积的最后一个元素由于旁边没有数，初始乘积应设为 1。
