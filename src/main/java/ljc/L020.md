## L020. 最长公共前缀 ✂️

题目描述

    编写一个函数来查找字符串数组中的最长公共前缀如果不存在公共前缀 返回空字符串 ""

核心思路

    按列扫描 Column Scan

    从第 0 列开始逐列比较  
    以第一个字符串作为基准  
    取出第 i 个字符 c  
    依次检查其它字符串在第 i 位是否存在 且字符是否等于 c  
    一旦遇到字符串长度不够 或 字符不一致  
    立即返回第一个字符串的 0 到 i 的子串作为结果

复杂度分析

    时间复杂度 O(S) — 为所有字符串字符总数 最坏情况下需要扫描所有字符

    空间复杂度 O(1) — 只使用常数个变量 不额外开数组或哈希结构

关键点总结

    先判断边界 strs 为空 或 长度为 0 直接返回空串  
    比较前先判断 i 是否越界 i >= s.length() 避免 charAt 越界  
    返回 substring(0, i) 因为第 i 列已经不满足 公共前缀只到 i-1  
    不使用 split 或哈希表 避免额外空间和不必要复杂度
