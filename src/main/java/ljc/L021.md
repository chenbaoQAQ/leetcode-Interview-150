## L021. 反转字符串中的单词 ✂️

题目描述

    给你一个字符串 s ，请你反转字符串中 单词 的顺序。

    单词 是由非空格字符组成的字符串。s 中使用至少一个空格将字符串中的 单词 分隔开。

    返回 单词 顺序颠倒且 单词 之间用单个空格连接的结果字符串。
核心思路 🧠

    倒序双指针扫描 (Backward Dual Pointer Scan)：

        考虑到我们要反转单词顺序，直接从字符串 末尾 向前扫描是最直观的思路。

    单词边界锁定：

        寻找尾巴 (End)：指针 i 从后往前跳过所有空格，直到遇到第一个非空格字符，此时 i 指向单词的结尾。

        寻找头部 (Start)：从 end 开始继续向前，直到遇到第一个空格（或到达索引 -1），此时 i + 1 就是单词的起始位置。

    高效拼接：

        使用 StringBuilder 容器接收切下的单词（使用 substring 方法），并在单词后手动追加一个空格。

    结果修整：

        最后将 StringBuilder 转为字符串，并调用 trim() 去除末尾多出的那个空格。

复杂度分析 📊

    时间复杂度: O(n) — 字符串整体被扫描了一遍，虽然有嵌套循环，但指针 i 是一路向前的。

    空间复杂度: O(n) — StringBuilder 需要存储最终的字符串结果。

关键点总结 🔑

    跳过冗余空格：通过 while (s.charAt(i) == ' ') i-- 逻辑，可以自动处理前导、尾随及单词间的多个空格。

    指针安全：在每一次 i 递减的操作中，必须前置检查 i >= 0 以防止 StringIndexOutOfBoundsException。

    左闭右开：调用 s.substring(i + 1, end + 1) 时，注意 Java API 的特性，起始索引包含在内，结束索引不包含在内。

    原生首选：避免使用 split("\\s+")，手写双指针能体现更强的算法功底和对 O(1) 额外空间（不计结果集）的极致控制。
