📝 L009. 跳跃游戏 🏃‍♂️

        给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个下标。
核心思路

    贪心算法 (维护最远距离)：我们关注在每一个可达的位置上，我们“最远”能延伸到哪里。

    可达性判断：如果当前下标 i 已经超过了 maxreach，说明路径中断，无法继续。

    提前结束：一旦 maxreach 大于或等于数组的最后一个索引，就可以确定能够到达。

复杂度分析

    时间复杂度: O(n) — 数组只需遍历一次。

    空间复杂度: O(1) — 只需要一个变量 maxreach。

关键点总结

    边界处理：你代码里的 maxreach >= nums.length 其实可以微调为 maxreach >= nums.length - 1，因为只要能覆盖到最后一个下标即可。

    逻辑严密：对于 nums = [0] 这种特殊情况，你的代码也能正确返回 true。
