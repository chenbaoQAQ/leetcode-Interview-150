L003. 删除有序数组中的重复项 👥

    给你一个 非严格递增排列 的数组 nums ，请你 原地 删除重复出现的元素，使每个元素 只出现一次 ，返回删除后数组的新长度。
核心思路

    对比法双指针：

        slow 指向当前已确定的不重复序列的最后一个。

        fast 向后寻找与 nums[slow] 不同的新元素。

    更新条件：当 nums[fast] != nums[slow] 时，slow 前进一步并接收新值。

复杂度分析

    时间复杂度: O(n) — 遍历一次数组。

    空间复杂度: O(1) — 原地修改。

关键点总结

    初值设定：数组有序，第一个元素必保留，所以 slow 从 0 开始，fast 从 1 开始。
