L011. H 指数 🎓

        给你一个整数数组 citations ，其中 citations[i] 表示研究者的第 i 篇论文被引用的次数。计算并返回该研究者的 h 指数。根据定义，h 代表“高引用次数”，一名科研人员的 h 指数是指他（她）至少发表了 h 篇论文，并且至少有 h 篇论文被引用次数大于等于 h。
核心思路

    排序遍历法：将数组从大到小排序。遍历排序后的数组，如果当前论文的引用次数 citations[i] 大于等于当前的论文篇数 i + 1，则说明 h 至少可以是 i + 1。

    计数排序法（进阶）：如果不想排序，可以使用一个计数数组记录每个引用次数出现的频率。因为 h 指数不可能超过总论文数 n。

复杂度分析

    时间复杂度: O(nlogn) — 如果使用系统自带排序。

    空间复杂度: O(1) 或 O(n) — 取决于排序算法是否占用额外空间。

关键点总结

    定义转换：h 指数实际上是找到一个最大的 h，使得有 h 个数 ≥h。

    临界值：排序后，第一个不满足 引用次数 >= 序号 的位置就是我们要找的边界。
