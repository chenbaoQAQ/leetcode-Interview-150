题目描述 📋

给你一个数组 nums 和一个值 val，你需要 原地（In-place） 移除所有数值等于 val 的元素，并返回移除后数组的新长度。

    不要使用额外的数组空间。

    元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

核心思路 🧠

    快慢双指针 (Fast-Slow Pointers)：

        快指针 (fast)：充当“侦察兵”，从头到尾扫描数组，寻找所有 不等于 val 的元素。

        慢指针 (slow)：充当“搬运工”，记录“新数组”下一个可以填入的位置。

    触发机制：

        当 nums[fast] != val 时，说明找到了一个需要保留的元素。

        将其覆盖到慢指针位置：nums[slow] = nums[fast]。

        慢指针向前移动一步：slow++。

    结果返回：

        循环结束后，slow 的数值刚好等于被搬运的合格元素总数，即新数组的长度。

复杂度分析 📊

    时间复杂度: O(n) — 数组只需遍历一次。

    空间复杂度: O(1) — 直接在原数组上修改，不消耗额外空间。

关键点总结 🔑

    索引 vs 数值：注意 if 判断的是 nums[fast] 的数值，而不是索引 fast 本身。

    覆盖逻辑：这种方法实际上是将合格的元素“推”到了数组的前部，而被移除的元素则被覆盖或留在了数组尾部。
