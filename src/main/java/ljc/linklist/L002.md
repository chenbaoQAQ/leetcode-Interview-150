
L002. 两数相加 (Add Two Numbers) ➕
题目描述 📋
      
      给你两个 非空 的链表，表示两个非负的整数。它们每位数字都是按照 逆序 的方式存储的，每个节点只能存储 一位 数字。请你将两个数相加，并以链表形式返回表示结果的链表。
   
       输入：(2 -> 4 -> 3) + (5 -> 6 -> 4) （即 342+465）
   
       输出：7 -> 0 -> 8 （即 807）

核心物理模型：动态铺路 🏗️

      在这道题中，我们不再是修改现有的链表，而是从无到有地建造一条新链表。你悟出的“虚拟头节点”就是这里的关键。
      1. 虚拟头节点 (Dummy Node) —— 物理起跑架
      
         痛点：链表没有数组那样的“第 0 位”。直接创建第一个节点需要处理麻烦的 if(head == null) 特判。
      
         方案：人工制造一个 第 -1 位（即 dummy）。它是一个不存实际数据的“锚点”。
      
         意义：让所有真实的数据节点（个位、十位...）都能统一通过 curr.next = new ListNode(...) 来挂载。

2. “先焊接，再走人” —— 链表生长三部曲

         每当算出一位的结果（例如 x+y+carry）后，执行以下动作：
         
             计算 (Sum & Carry)：算出当前位的值 sum % 10 和进位 sum / 10。
         
             焊接 (curr.next = ...)：在当前位置后面开辟一个新空间。此时由于 curr 连着 dummy，新空间也就接在了结果链表上。
         
             位移 (curr = curr.next)：工人向前走一步，踩在刚刚造好的新空间上，准备接下一节。
