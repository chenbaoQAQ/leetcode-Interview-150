L016. 接雨水 🌧️

        给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。
核心思路

    短板理论：对于每个位置 i，它能接的水量取决于 min(左侧最高墙,右侧最高墙)−当前高度。

    双指针法：

        设置 left 和 right 指针分别指向首尾。

        使用 leftMax 和 rightMax 维护两端的“防线”。

        贪心策略：如果 leftMax < rightMax，说明无论右边多高，当前的瓶颈都在左边，因此我们放心地处理左边并向右移动。

    状态转移：

        若 currentHeight < Max：水被接住，累加差值。

        若 currentHeight >= Max：墙太高接不住水，更新 Max。

复杂度分析

    时间复杂度: O(n) — 左右指针各移动一遍，总计一次遍历。

    空间复杂度: O(1) — 仅使用 4 个整数变量，不随输入规模增长。

关键点总结

    为什么双指针可行？：因为我们不需要知道对面那一侧具体的每一根柱子，只需要知道对面有一根“比我这边最高墙还要高”的柱子，就能确定当前的存水上限。

    初始化：起始时将 leftMax 和 rightMax 设为首尾柱子的高度，这样能正确处理边界。
