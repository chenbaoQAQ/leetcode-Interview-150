L023. 找出字符串中第一个匹配项的下标 🔍
题目描述 📋

      给你两个字符串 haystack 和 needle ，请你在 haystack 字符串中找出 needle 字符串的第一个匹配项的下标（下标从 0 开始）。如果 needle 不是 haystack 的一部分，则返回 -1 。
核心思路 🧠
暴力匹配（滑动窗口 + 双指针）

    窗口设定：

        needle 的长度为 m。我们只需要在 haystack 中检查所有长度为 m 的子串。

        工程优化：如果 haystack 剩余字符不足 m 个，则不可能匹配成功。因此外层循环只需遍历至 i <= n - m。

    双指针比对：

        外层指针 i：标记 haystack 中当前尝试匹配的起始位置。

        内层指针 j：标记当前正在比对 needle 中的第几个字符。

        匹配动作：

            若 haystack.charAt(i + j) == needle.charAt(j)，则 j 向后移动继续比对。

            若比对中断，则外层循环 i++，开启下一个起点的尝试。

    结果判断：

        如果 j 成功走到了 m（即 j == needle.length()），说明找到了完全匹配的项，直接返回当前的起始下标 i。

复杂度分析 📊

    时间复杂度: O(n×m) —— 其中 n 为 haystack 长度，m 为 needle 长度。最坏情况下（如 aaaaa 匹配 aaaab），需要遍历大部分字符。

    空间复杂度: O(1) —— 只使用了常数个指针变量，没有开辟额外空间。

关键点总结 🔑

    回溯逻辑：当 ssad 与 sad 匹配时，第一位 s 匹配后，第二位 s 与 a 冲突。此时 j 归零，i 移动到下一个 s 重新开始，这保证了不会漏掉正确的匹配项。

    边界控制：外层循环的 n - m 限制是防止 charAt(i + j) 发生越界异常（StringIndexOutOfBoundsException）的重要保障。
