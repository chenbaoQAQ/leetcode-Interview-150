L017. 罗马数字转整数 🏛️

        将给定的罗马数字字符串转换为整数。罗马数字由七个不同的符号表示。
核心思路

    反向思维：罗马数字的组合规则决定了右侧的数字通常比左侧大或相等。

    减法触发条件：

        如果 Value(s[i])<Value(s[i+1])，则表示这是一个减法组合（如 IV）。

        否则，按常规累加。

    实现技巧：从右向左遍历字符串，可以非常方便地通过比较当前值与上一个值（右侧值）来决定加减，无需向后探测。

复杂度分析

    时间复杂度: O(n) — 字符串遍历一次。

    空间复杂度: O(1) — 虽然用了哈希表，但其大小固定（7个字符），属于常数空间。

关键点总结

    Map 初始化：预先存储 7 个字符的对应数值。

    指针方向：从后往前遍历比从前往后处理特殊情况（判断 i+1）更简洁
