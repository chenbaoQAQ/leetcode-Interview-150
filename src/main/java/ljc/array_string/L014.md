L014. 加油站 ⛽

        在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。你有一辆油箱容量无限的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。判断是否能绕环路行驶一周。
核心思路

    全局判断：如果 ∑gas<∑cost，说明汽油总量根本不足以支撑行驶完全程，直接返回 -1。

    局部贪心：

        我们从 0 号站尝试出发。

        如果行驶到 i 站时油量耗尽（currentSum < 0），说明 [0,i] 之间的任何一个站都不能作为起点到达 i+1。

        此时，我们将起点“贪心”地跳跃到 i+1 重新尝试。

    唯一性保证：题目保证如果存在解，则该解是唯一的。

复杂度分析

    时间复杂度: O(n) — 只需要遍历一次加油站列表。

    空间复杂度: O(1) — 仅使用了几个记录油量和起点的变量。

关键点总结

    净油量概念：每一站的盈亏 net = gas[i] - cost[i] 是核心关注点。

    断点跳跃：一旦在某处断掉，之前的路段都可以直接排除，这是 O(n) 算法能跑通的关键。
