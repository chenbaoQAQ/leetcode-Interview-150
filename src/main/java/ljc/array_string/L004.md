L004. 删除有序数组中的重复项 II 👥👥

在 L003 的基础上，要求每个元素 最多出现两次。
核心思路

    跨步对比法 (通用解法)：

        比较 nums[fast] 和 nums[slow - 2]。

        如果不相等，说明当前数字还没重复到 3 次，可以填入。

    计数模拟法 (直观解法)：使用 count 变量记录当前数字出现的频率，逻辑更接近业务思维。

复杂度分析

    时间复杂度: O(n) — 线性扫描。

    空间复杂度: O(1) — 仅需少量变量。

关键点总结

    K 位通解：如果要保留最多 K 个重复项，只需将对比逻辑改为 nums[slow - K]。
