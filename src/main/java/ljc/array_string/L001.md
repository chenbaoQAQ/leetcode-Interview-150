
L001. 合并两个有序数组 📥

    将两个有序整数数组 nums1 和 nums2 合并。nums1 有足够的空间容纳 nums2。合并后应保持有序。
核心思路

    逆向双指针：为了避免覆盖 nums1 前面的元素，我们从后往前填充。

    比较与安置：比较 nums1 和 nums2 末尾的有效元素，将较大的那个放到 nums1 的最后面（索引为 m + n - 1）。

复杂度分析

    时间复杂度: O(m+n) — 两个数组各遍历一遍。

    空间复杂度: O(1) — 直接在 nums1 上修改。

关键点总结

    边界处理：如果 nums2 还有剩余，需要全部拷贝到 nums1 前面。

    倒序优势：不需要额外空间，原地（In-place）完成。
