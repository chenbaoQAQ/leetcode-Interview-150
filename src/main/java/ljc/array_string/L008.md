L008. 买卖股票的最佳时机 II 💰

        给你一个整数数组 prices ，其中 prices[i] 表示某支股票第 i 天的价格。在每一天，你可以决定是否购买和/或出售股票。你在任何时候 最多 只能持有 一股 股票。你可以在同一天多次买卖。返回你能获得的 最大 利润。
核心思路

    贪心算法 (捕捉所有上坡)：由于可以无限次交易，只要明天的价格比今天高，我们今天买入、明天卖出就一定能获利。

    利润分解：连续上涨的价格 A,B,C,D（且 A<B<C<D），其最大利润 D−A 实际上等于 (B−A)+(C−B)+(D−C)。通过累加所有相邻的正差值，我们就能拿到所有上涨波段的利润。

复杂度分析

    时间复杂度: O(n) — 只需要一次线性扫描。

    空间复杂度: O(1) — 只需一个变量存储总利润。

关键点总结

    与 L007 的区别：L007 只能交易一次（找全局波谷波峰）；L008 可以交易无限次（抓走所有上坡）。

    逻辑本质：不需要真的模拟交易过程，只需要计算所有“明天的增量”。
