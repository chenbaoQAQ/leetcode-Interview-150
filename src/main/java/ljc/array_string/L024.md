L024. 文本左右对齐 (Text Justification) 📄
题目描述 📋

给定一个单词数组 words 和一个长度 maxWidth，重新排版单词，使其成为每行恰好有 maxWidth 个字符，且左右两端对齐的文本。

    贪心原则：每行应包含尽可能多的单词。

    对齐规则：空格应均匀分配。如果不能均分，左侧间隙的空格数要多于右侧。

    特例：最后一行和单单词行应左对齐，单词间只留一个空格，末尾补齐。

核心物理模型 🧠

我们将排版过程拆解为三个步骤，类似于工厂的“装箱”流程：
1. 探测器 (findRight) —— 确定装箱范围

通过“单词长 + 保底空格长”来判断当前行能塞进多少单词。

    公式：sumLen + wordLen + minSpace <= maxWidth。

    结果：返回 right 指针，确定当前行的单词区间为 [left, right)。

2. 分配器 (justify) —— 核心数学计算

计算如何把多出来的空格（totalSpaces）塞进间隙（gapCount）里。

    基础空格：avgSpaces = totalSpaces / gapCount。

    多余空格：extraSpaces = totalSpaces % gapCount。

    分配逻辑：前 extraSpaces 个间隙分配 avgSpaces + 1 个空格，其余分配 avgSpaces 个。

3. 边界处理 —— 特殊情况

   单单词行：gapCount == 0，无法进行除法运算，直接左对齐。

   最后一行：isLast == true，即使有多个单词，也必须左对齐，且单词间仅保留一个空格。

复杂度分析 📊

    时间复杂度: O(L) —— L 是所有单词的字符总数。我们只对每个单词进行了一次扫描和一次字符串拼接。
