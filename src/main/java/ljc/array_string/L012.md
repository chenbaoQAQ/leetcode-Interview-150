L012. O(1) 时间插入、删除和获取随机元素 🎲

        实现 RandomizedSet 类，使得 insert、remove 和 getRandom 操作的时间复杂度均为 O(1)。
核心思路

    组合数据结构：

        ArrayList：由于元素在内存中连续存储，可以通过索引在 O(1) 时间内完成 getRandom（使用随机数生成器产生索引）。

        HashMap：记录每个值对应的数组下标，使得 insert 和 remove 前的查找操作达到 O(1)。

    删除技巧 (Swap with Last)：

        在数组中删除非末尾元素通常需要 O(n) 时间移动后续元素。

        解法：将待删除元素与数组最后一个元素交换位置（或者直接用末尾元素覆盖目标位置），然后仅删除数组的最后一位，从而将复杂度降至 O(1)。

复杂度分析

    时间复杂度: 全部操作均为 O(1)。

    空间复杂度: O(n) — 需要存储 n 个元素的数值和索引。

关键点总结

    随机性：必须使用支持索引随机访问的结构（如数组/列表），链表或纯哈希表无法直接实现 O(1) 随机。

    同步更新：在 remove 交换元素时，必须同时更新哈希表中那个“被移动的末尾元素”的新索引。
