# L010. 跳跃游戏 II 👟

给你一个非负整数数组 `nums` ，你最初位于数组的第一个下标。每个元素代表你在该位置可以跳跃的最大长度。目标是使用最少的跳跃次数到达数组的最后一个下标。假设你总是可以到达数组的最后一个下标。

## 核心思路
- **贪心策略 (最远潜力点)**：在当前能跳到的范围内，观察每一个点作为“起跳点”能达到的最远距离。
- **边界触发**：维护一个当前步数能覆盖到的最远边界 `end`。当我们移动到 `end` 时，说明当前这一跳已经用尽，必须触发下一跳。
- **窗口移动**：每一跳都会产生一个新的“覆盖窗口”，我们只需计算为了覆盖终点共需要开启多少个窗口。

## 复杂度分析
- **时间复杂度**: O(n) — 线性扫描数组一次。
- **空间复杂度**: O(1) — 只需常数级变量记录步数和边界。

## 关键点总结
- **遍历范围**：只需要遍历到 `n - 2`（倒数第二个元素）。因为一旦到达或超过 `end` 触发了最后一次跳跃，`end` 就会覆盖 `n - 1`。
- **局部最优 vs 全局最优**：通过每一步都寻找能让下一跳最远的路径，最终达成总步数最少。
