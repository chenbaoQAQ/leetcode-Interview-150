L015. 分发糖果 🍬

        给你一个整数数组 ratings，表示每个孩子的评分。
        你需要按照以下要求分发糖果：每个孩子至少 1 颗；相邻两个孩子中，评分更高的获得更多糖果。计算并返回最少糖果数。
核心思路

    双向贪心策略：

        左规则：只要右边比左边评分高，右边的糖果就比左边多 1 个。

        右规则：只要左边比右边评分高，左边的糖果就比右边多 1 个。

    取其大者：对于任何一个位置 i，它必须同时满足左右两边的约束。
    因此，最终的糖果数是 max(left[i],right[i])。

    空间技巧：

        left 数组存储左向规律的结果。

        在反向遍历时，使用单变量 right 实时计算结果并求和，无需额外开辟 right 数组。

复杂度分析

    时间复杂度: O(n) — 两次独立的线性扫描。

    空间复杂度: O(n) — 需要一个数组存储一侧的扫描结果。

关键点总结

    持平处理：如果两个相邻孩子评分相同，题目并没有要求他们糖果数必须相同或不同。
            为了“最少”，我们此时只需给当前孩子分发 1 颗。

    两次遍历的必要性：由于每个元素受左右两个邻居的影响，
                   这种“拆解约束再取最大”的方法能完美处理复杂的波峰和波谷。
