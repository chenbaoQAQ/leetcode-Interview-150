L007. 买卖股票的最佳时机
题目描述 📋

给定一个数组 prices ，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。你只能选择 某一天 买入这只股票，并选择在 未来的某一个不同的日子 卖出该股票。设计一个算法来计算你所能获取的最大利润。如果你不能获取任何利润，返回 0 。
核心思路

    贪心思想 / 动态规划：我们不需要知道每一天具体的利润，只需要找到“历史最低点”买入，并在之后尽可能高的点卖出。

    实时更新：遍历数组时，我们不断更新两个关键信息：

        到目前为止的最低价格。

        如果今天卖出，能得到的最大利润。

复杂度分析

    时间复杂度: O(n) — 只需要对数组进行一次线性扫描。

    空间复杂度: O(1) — 只使用了常数级的额外变量。

关键点总结

    顺序性：卖出动作必须发生在买入之后，所以我们是在遍历的过程中动态对比。

    初值选择：最低价格通常初始化为一个很大的数，确保第一个遇到的价格能顺利成为初始最低价。
