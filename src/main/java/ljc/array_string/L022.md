## L022. Z 字形变换 📐
题目描述 📋

      将一个给定字符串 s 根据给定的行数 numRows ，以从上往下、从左到右进行 Z 字形排列。比如输入字符串为 "PAYPALISHIRING" 行数为 3 时，排列如下：
      Plaintext
      
      P   A   H   N
      A P L S I I G
      Y   I   R
      
      之后，你的输出需要从左往右逐行读取，产生出一个新的字符串。
核心思路 🧠
1. 你的直觉：周期方块法 (Periodic Block)
      
         规律发现：Z 字形实际上是由一个个“V”字型循环组成的。
      
         周期计算：一个完整的“V”字循环包含的字符数 T=2×numRows−2。
      
         数学映射：对于索引为 i 的字符，通过 i % T 可以确定它在周期内的位置：

         向下走：当 mod < numRows，行号直接就是 mod。
   
         向上斜：当 mod >= numRows，行号会“折返”。

   2. 推荐解法：弹跳方向法 (Direction Toggle)

      行桶策略：
   
            创建 numRows 个 StringBuilder，每个代表一行。

         模拟弹跳：

              设定一个当前行 curRow 和一个方向标志 flag（1 代表向下，-1 代表向上）。

              遍历字符串，把字符扔进对应的行桶。

              转向逻辑：当到达 第一行 (0) 或 最后一行 (numRows-1) 时，将 flag 取反（flag = -flag）。

复杂度分析 📊

    时间复杂度: O(n) — 遍历一遍字符串即可。

    空间复杂度: O(n) — 需要存储所有字符的 StringBuilder 数组。

关键点总结 🔑

    边界处理：如果 numRows < 2，直接返回原字符串，因为无法形成 Z 字。

    高效拼接：最后将所有 StringBuilder 按顺序 append 到一起。
